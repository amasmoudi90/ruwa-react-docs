# Ruwa React docs

Documentation of the Ruwa (رُوى) React theme for Salla stores, in Arabic and English.

Live site: https://amasmoudi90.github.io/ruwa-react-docs/

```bash
npm install
npm run dev     # local preview
npm run build   # static site in docs/.vitepress/dist
```

Every push to `main` publishes the site through GitHub Pages (`.github/workflows/deploy.yml`). In the repository's
settings, set Pages → Source to "GitHub Actions" once.
