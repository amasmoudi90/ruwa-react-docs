# إعدادات الثيم

## زاهية: الألوان والشعار والوضع

| الإعداد | ما يفعله |
|---|---|
| لون العلامة (اختياري) | يستبدل لون المتجر في كل الثيم. اتركه فارغاً ليتبع الثيم لون متجرك في سلة. |
| شعار الوضع الفاتح / شعار الوضع الداكن (اختياري) | شعار مختلف لكل وضع، مثلاً شعار فاتح على الخلفية الداكنة. إن تُرك فارغاً يظهر شعار المتجر. |
| اللون الناعم | لون الخلفيات الهادئة في بعض العناصر (الوردي الفاتح افتراضياً). |
| الوضع الافتراضي | فاتح، أو داكن، أو حسب جهاز الزائر. |
| زر تبديل الوضع في الهيدر | يسمح للزائر بالتبديل بين الفاتح والداكن، ويُحفظ اختياره. |
| خطوط زاهية للأحرف اللاتينية | خط عرض مميز للعناوين الإنجليزية. النص العربي يبقى بخط متجرك. أطفئه إن لم ترد تحميل خطوط من Google. |

## زاهية: الشريط العلوي المتحرك

| الإعداد | ما يفعله |
|---|---|
| إظهار الشريط العلوي المتحرك | شريط نصوص فوق الهيدر، مثل «شحن مجاني...». |
| النصوص | نص أو أكثر، يُعرض بالتتابع. |
| لون الخلفية | لون الشريط. |
| تحريك النصوص | تمرير النصوص باستمرار، ويتوقف عند مرور الفأرة. |

## زاهية: النافذة المنبثقة (عرض)

| الإعداد | ما يفعله |
|---|---|
| إظهار نافذة العرض | نافذة ترحيب بعرض أو كوبون، مطفأة افتراضياً. |
| تأخير الظهور (ثوانٍ) | بعد كم ثانية تظهر (من ٠ إلى ٦٠). |
| الصورة، العنوان، النص، نص الزر، رابط الزر | محتوى النافذة. |

تظهر مرة واحدة لكل زيارة (جلسة متصفح).

## زاهية: الهيدر

| الإعداد | ما يفعله |
|---|---|
| تخطيط الهيدر | **عائم** (بطاقة عائمة بتصميم زاهية)، أو تخطيطا الثيم الأساسي. |
| عرض القائمة الرئيسية في سطر واحد مع قائمة «المزيد» | الروابط الزائدة تنتقل إلى «المزيد» بدل سطر ثانٍ. |
| تثبيت القائمة الرئيسية أعلى الصفحة | يبقى الهيدر ظاهراً عند التمرير. |
| عرض معلومات المتجر، شريط علوي داكن، روابط الصفحات الهامة | خيارات التخطيطين الأساسيين. |

**السلة الجانبية:** على الحاسوب والجهاز اللوحي، الضغط على أيقونة السلة يفتح سلة جانبية فيها المنتجات والإجمالي و«إتمام الطلب». إن كان في السلة منتج بخيارات، يمر «إتمام الطلب» بصفحة السلة أولاً. على الجوال، زر السلة في الشريط السفلي يفتح صفحة السلة.

## زاهية: الفوتر

| الإعداد | ما يفعله |
|---|---|
| ساعات العمل، العنوان | تظهر مع بيانات التواصل من إعدادات متجرك. |
| عمود الانضمام: العنوان، النص، نص الزر، الرابط | دعوة للتسجيل. بلا رابط، يفتح الزر نافذة التسجيل في سلة للزوار. |
| اسم المتجر كبيراً أسفل الفوتر | اسم المتجر بخط ضخم. |
| النص الكبير | نص بدل اسم المتجر (اختياري). |
| صورة تملأ النص (اختياري) | صورة تظهر داخل حروف النص الكبير. |

فوتر زاهية بلون علامتك دائماً، فإعداد «الوضع الداكن» في قسم الفوتر لا يغيّره. قائمة الفوتر، ووسائل الدفع، والرقم الضريبي، وشهادة المركز السعودي للأعمال تأتي من إعدادات متجرك.

## صفحة المنتج وبطاقة المنتج

| الإعداد | ما يفعله |
|---|---|
| إظهار مسار التنقل في صفحة المنتج | مطفأ افتراضياً. |
| إظهار زر طرح سؤال | زر يفتح واتساب المتجر أو بريده. |
| نص تبويب الشحن والاسترجاع | يظهر في تبويب «الشحن والاسترجاع». اتركه فارغاً لإخفاء التبويب. |
| إظهار مسار التنقل في صفحة قائمة المنتجات | مطفأ افتراضياً. |
| تفعيل إشعار الإضافة للسلة المحسن | نافذة صغيرة بعد الإضافة فيها المنتج وأزرار السلة. |
| إظهار زر «أعلمني عند التوفر» في البطاقة | للمنتجات النافدة. |
| تثبيت زر الإضافة والكمية أسفل شاشة الجوال | |
| إظهار الوسوم | وسوم المنتج في صفحته. |
| طريقة عرض الصور / تكبير الصور في سليدر صور المنتج | ملء الإطار أو احتواء الصورة، وتكبير عند المرور. |

## إعدادات الثيم الأساسي

خيارات قسم «الصفحة الرئيسية» (طريقة عرض الصور المربعة، الوضع العمودي للمنتجات الثابتة، زر «الكل») تخص عناصر الثيم الأساسي، لا عناصر زاهية.
