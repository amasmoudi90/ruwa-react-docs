# عناصر الصفحة الرئيسية

كل عنصر يبدأ بنصوص وصور مؤقتة؛ استبدلها بصورك ونصوصك. النصوص العربية الافتراضية تظهر بالإنجليزية في صفحات اللغة الإنجليزية ما لم تغيّرها. حقول المنتجات والصور فارغة في البداية، فيمكن حفظ أي عنصر دون تعبئته.

## عناصر زاهية

| العنصر | لماذا تستخدمه | أهم الإعدادات |
|---|---|---|
| زاهية: سلايدر رئيسي | صورة أو فيديو بملء الشاشة بعنوان كبير | الشرائح (صورة، صورة للجوال، فيديو MP4/WebM، نصوص، زر)، التشغيل التلقائي، المدة، الارتفاع، محاذاة النص، لون النص |
| زاهية: نص ترحيبي | فقرة في وسط الصفحة | عنوان صغير، عنوان، وصف، زر |
| زاهية: بنرات ترويجية | من بنر إلى ٤ بعناوين فوق الصورة | الصورة، العنوان، العنوان الفرعي، الرابط |
| زاهية: عرض منتجات | منتجات في شريط متحرك أو شبكة | مصدر المنتجات (أحدث، تصنيف، ماركة، وسم، أو منتجات تختارها)، العدد، التخطيط، الأعمدة، زر «عرض الكل» |
| زاهية: صورة مع نص | صورة بجانب نص، أو نص فوق صورة، أو لوحة ملونة | التخطيط، جهة الصورة، لون اللوحة |
| زاهية: الأسئلة الشائعة | أسئلة تنفتح عند الضغط، مع صورة | الأسئلة والأجوبة، إظهار الصورة |
| زاهية: رأي عميل كبير | رأي واحد كبير في كل مرة | التقييم، العنوان، النص، الاسم، الصفة، الصورة |
| زاهية: عرض منتج بعداد | منتج عليه خصم بعداد تنازلي | المنتج، تاريخ الانتهاء (نص بصيغة `2026-12-31 23:59`؛ إن تُرك فارغاً يُستخدم موعد انتهاء خصم المنتج)، صورة، وصف |
| زاهية: شريط نصوص متحرك | كلمات تتحرك عبر الصفحة | النصوص (مع صورة اختيارية)، السرعة، الحجم، الألوان |
| زاهية: قبل وبعد | مقارنة صورتين بالسحب | الصورتان وعنواناهما |
| زاهية: صورة تسوق | صورة عليها نقاط تفتح منتجات | الصورة، النقاط (المنتج، الموضع الأفقي والعمودي بالنسبة المئوية) |
| زاهية: ريلز تسوق | صور أو فيديوهات بمنتج على كل منها | المنشورات (صورة، فيديو، منتج)، زرّا متابعة |
| زاهية: مزايا المتجر | من ميزة إلى ٤ بأيقونات | الأيقونة، العنوان، النص، الرابط |
| زاهية: صور التصنيفات | مربعات صور تقود إلى تصنيفات | الصور والروابط |
| زاهية: شبكة الماركات | شعارات الماركات | الماركات |
| زاهية: مقالات المدونة | آخر المقالات أو مقالات تختارها | المقالات، العدد، زر «عرض الكل» |
| زاهية: آراء العملاء | عدة آراء في شريط | الآراء |
| زاهية: معرض صور | صور حساباتك على وسائل التواصل | الصور، رابط الحساب |
| زاهية: انضم إلينا | شريط دعوة للتسجيل | النصوص، الزر، الرابط، لون الخلفية |

لا يدعم سلة الاشتراك في النشرة البريدية من الثيم، لذلك «انضم إلينا» زر وليس حقل بريد: يتبع رابطك، أو يفتح نافذة التسجيل للزوار.

## عناصر الثيم الأساسي

عناصر الثيم الأساسي الـ١١ (صور متحركة، روابط سريعة، منتجات مميزة، الماركات، المدونة، وغيرها) ما زالت متاحة.

## صفحة رئيسية مقترحة

بهذا الترتيب تقريباً: سلايدر رئيسي، نص ترحيبي، بنرات ترويجية، عرض منتجات، صورة مع نص، الأسئلة الشائعة، رأي عميل كبير، عرض منتج بعداد، شريط نصوص متحرك، قبل وبعد، صورة تسوق، ريلز تسوق، مزايا المتجر. يمكن إضافة العنصر نفسه أكثر من مرة، مثل سلايدر ثانٍ في الأسفل.

## نصائح

- استخدم صوراً بنسب متقاربة داخل العنصر الواحد، وصورة جوال مستقلة في السلايدر الرئيسي عند الحاجة.
- جرّب صفحاتك بالوضع الداكن إن تركت زر التبديل ظاهراً.
