# Theme settings

## Ruwa: colours, logo and mode

| Setting | What it does |
|---|---|
| Brand colour (optional) | Replaces the store colour across the theme. Leave it empty to follow your Salla store colour. |
| Light-mode logo / dark-mode logo (optional) | A different logo per mode, for example a light logo on the dark background. Empty shows the store logo. |
| Soft colour | The calm background colour in some blocks (light pink by default). |
| Default mode | Light, dark, or the visitor's device setting. |
| Mode switch in the header | Lets visitors switch between light and dark; their choice is remembered. |
| Ruwa fonts for Latin letters | A display font for English headings. Arabic keeps your store's font. Turn it off to load no fonts from Google. |

## Ruwa: scrolling top bar

| Setting | What it does |
|---|---|
| Show the top bar | A text bar above the header, such as "Free shipping...". |
| Texts | One or more texts, shown in turn. |
| Background colour | The bar's colour. |
| Animate the texts | Scrolls the texts continuously; pauses on hover. |

## Ruwa: offer popup

| Setting | What it does |
|---|---|
| Show the offer popup | A welcome popup with an offer or coupon. Off by default. |
| Delay (seconds) | How long before it appears (0 to 60). |
| Image, title, text, button text, button link | The popup's content. |

It shows once per visit (browser session).

## Ruwa: header

| Setting | What it does |
|---|---|
| Header layout | **Floating** (Ruwa's floating card), or the base theme's two layouts. |
| Main menu on one line with a "More" menu | Extra links move into "More" instead of a second line. |
| Sticky main menu | The header stays visible while scrolling. |
| Store info, dark top bar, important links | Options for the two base layouts. |

**Cart drawer:** on computers and tablets the bag icon opens a side cart with the items, the total and "Complete
order". If an item has options, "Complete order" goes through the cart page first. On phones, the cart tab in the
bottom bar opens the cart page.

## Ruwa: footer

| Setting | What it does |
|---|---|
| Opening hours, address | Shown with the contact details from your store settings. |
| Join column: title, text, button text, link | A sign-up invitation. With no link, the button opens Salla's sign-up window for guests. |
| Store name large under the footer | The store's name in huge letters. |
| Large text | Text to show instead of the store's name (optional). |
| Image inside the text (optional) | A photo shown through the letters of the large text. |

Ruwa's footer always uses your brand colour, so the footer section's "Dark mode" setting doesn't change it. The
footer menu, payment methods, tax number and Saudi Business Center certificate come from your store settings.

## Product page and product card

| Setting | What it does |
|---|---|
| Breadcrumbs on the product page | Off by default. |
| "Ask a question" button | Opens the store's WhatsApp or email. |
| Shipping & returns tab text | Shown in the "Shipping & Returns" tab. Leave it empty to hide the tab. |
| Breadcrumbs on product lists | Off by default. |
| Improved added-to-cart notice | A small window after adding, with the product and cart buttons. |
| "Notify me when available" on the card | For sold-out products. |
| Sticky add button and quantity on phones | |
| Show tags | The product's tags on its page. |
| Image fit / zoom in the product gallery | Fill the frame or fit the photo, and zoom on hover. |

## Base theme settings

The "Home page" options (square photo fit, vertical fixed products, the "All" button) apply to the base theme's
blocks, not to Ruwa's.
