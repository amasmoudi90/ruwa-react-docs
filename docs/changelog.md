# سجل التحديثات

## الإصدار 1.0 (قريباً)

أول إصدار من رُوى على محرك Twilight React من سلة:

- ١٩ عنصراً خاصاً بالصفحة الرئيسية، منها سلايدر بالفيديو، قبل وبعد، صورة تسوق، ريلز تسوق، وعرض بعداد تنازلي.
- الوضعان الفاتح والداكن، مع شعار لكل وضع.
- العربية والإنجليزية في كل الصفحات.
- هيدر عائم، شريط علوي متحرك، ونافذة عرض ترحيبية.
- سلة جانبية على الحاسوب والجهاز اللوحي.
- صفحة منتج بتبويبات وزر طرح سؤال وزر إضافة ثابت على الجوال.
- فوتر بلون علامتك واسم متجرك بخط كبير.
